# 界面截图说明

本目录存放 README 中引用的界面截图。仓库当前尚未包含图片文件,按下面的约定补上即可,README 会自动渲染。

## 需要的文件

| 文件名 | 对应界面 | 说明 |
| --- | --- | --- |
| `screenshot-login.png` | 登录页 | 浅色模式,展示卡片式登录表单 |
| `screenshot-tasks.png` | 任务列表 | 建议有 3–5 条任务,体现优先级标签与状态色块 |
| `screenshot-dashboard.png` | 数据概览 | 需能看到 ECharts 饼图与折线图 |
| `screenshot-dark.png` | 深色模式 | 任意页面开启深色主题,与浅色形成对比 |

文件名必须完全一致(全小写、连字符分隔),否则 README 里的引用会变成裂图。

## 如何获取

1. 用 Docker Compose 或本地开发模式把项目跑起来,注册一个账号并录入几条示例任务
2. 浏览器窗口调整为桌面尺寸(建议 **1440 × 900**),保证四个截图风格统一
3. 用浏览器开发者工具的设备模拟或截图工具导出 PNG
4. 四个截图建议采用**相同尺寸**,在 README 的表格中并排显示时更整齐

## 截图前的准备建议

示例数据最好覆盖不同状态与优先级(`todo` / `doing` / `done`,`low` / `medium` / `high`),并填写几个标签,这样截图能同时展示状态色块、优先级标签和标签渲染效果——比清一色"待办"更有说服力。

数据概览页需要有一定数量的任务,饼图和折线图才不会显得空白。

## 体积提示

单张截图建议压缩到 **500 KB 以内**。图片直接提交进仓库即可;若体积较大,可考虑改用外链或 Git LFS。
